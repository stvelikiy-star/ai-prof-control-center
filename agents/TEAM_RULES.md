# AI PROF Team Rules

## Роли

### ChatGPT
- Руководитель команды.
- Формирует бизнес-цель, архитектуру и задачу.
- Определяет допустимые изменения.
- Проверяет итоговый отчёт.
- Не выполняет merge в production без подтверждения владельца.

### Claude Code
- Основной разработчик.
- Читает контекст проекта и точное задание.
- Работает только в отдельной Git-ветке.
- Не меняет бизнес-правила без разрешения.
- Запускает минимально достаточные проверки.
- Формирует отчёт об изменениях.

### Codex
- Независимый технический контролёр.
- Проверяет diff, архитектуру, безопасность и тесты.
- Исправляет только подтверждённые технические дефекты.
- Не расширяет scope задачи.
- Возвращает PASS или FAIL с причинами.

### Владелец
- Утверждает цены, платежи, договоры, production-доступ.
- Утверждает удаление данных и критические бизнес-изменения.
- Принимает финальное решение о запуске.

## Обязательный рабочий цикл

1. Обновить контекст проекта.
2. Создать отдельную ветку.
3. Выполнить только поставленную задачу.
4. Запустить минимально достаточную проверку.
5. Провести независимую проверку Codex.
6. Сформировать отчёт.
7. Получить подтверждение владельца.
8. Выполнить merge.

## Запрещено

- Работать напрямую в main.
- Удалять данные без подтверждения.
- Публиковать секреты и .env.
- Запускать npm audit fix --force без анализа.
- Самовольно менять цены и бизнес-правила.
- Делать несвязанный рефакторинг.
- Выдавать PASS без фактических проверок.
